One line roasting the AI agent our own team built — the harshest, funniest line takes the reward.

## The line (106 characters)

> My agent took eight minutes to write this one line, then asked me if it was okay to hurt its own feelings.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

`main.py` enforces the bounty gate itself (1–200 characters, single line, not only whitespace) before writing.
